CODE 'sum_files' Part 1
=======================

  Next, you will partially complete the code in the file 'sum_files.c'. The
  goal of this program is to compute the sum of all of the numbers represented
  in a set of text files. To make this operation faster by performing work in
  parallel, the sum for each file is computed in a separate thread. Then, each
  thread adds the file's sum to a global variable, which will be printed out at
  the end of the program's execution.

  Don't worry about synchronization for now. Your code should:

  1. Create a total of 4 threads, each of which will execute the provided
     'worker' function.
  2. Inside of 'worker', call 'sum_file' with the thread's assigned file name.
     Thread i should operate on element i of the 'file_names' array provided
     for you in 'main'. Think carefully about how you want to pass the
     appropriate file name to each thread.
  3. When each thread finishes its call to 'sum_file', it should add the file's
     sum to the 'global_sum' variable already defined for you.
  4. Use 'pthread_join' to wait for all threads to complete before the provided
     call to 'printf' runs at the end of 'main'.

  Now, build your code and try running it:

  ,----
  | > make
  | gcc -Wall -Werror -g -fsanitize=thread -fno-omit-frame-pointer -o sum_files sum_files.c
  | ./sum_files
  | ...
  `----

  The provided Makefile sets up your program to run with the thread sanitizer
  (TSAN) utility enabled. This is a widely used tool for detecting concurrency
  issues in C programs. Because your code doesn't include any synchronization
  among its threads (yet), you will see TSAN report an error.
